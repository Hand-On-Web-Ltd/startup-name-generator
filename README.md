# Startup Name Generator

Need a name for your business? Pick an industry and a style, and this tool will generate 20 name suggestions using word combination logic. No API keys, no accounts — just open it in your browser.

Each suggestion links to a Namecheap domain search so you can check availability straight away.

## Features

- **4 naming styles** — Modern, Classic, Playful, Techy
- **Multiple industries** — Tech, Food, Health, Finance, Education, Creative, Retail, Services
- **20 names per batch** — Hit generate again for more options
- **Domain check links** — One click to check .com availability on Namecheap
- **Works offline** — Everything runs in the browser, no server needed
- **No dependencies** — Pure HTML, CSS, and JavaScript

## How to Use

1. Open `index.html` in your browser
2. Pick an industry from the dropdown
3. Choose a naming style
4. Click **Generate Names**
5. Click any name to check domain availability

## How It Works

The generator uses curated word lists for each industry and style combination. It applies different naming patterns:

- **Prefix + Root** — e.g. "NeoHealth", "QuickBite"
- **Root + Suffix** — e.g. "FoodFlow", "CodeHive"
- **Compound** — e.g. "BrightPath", "SwiftLeaf"
- **Modified** — e.g. "Stackd", "Grubly"
- **Abstract** — Invented words that sound good

The word lists are kept small enough to generate good names without needing a dictionary API or machine learning.
